# Pharmacy App – Full Stack Project

## 🚀 Project Overview
Pharmacy App is a comprehensive platform for managing medicines and pharmacy operations. It enables users to create, update, view, and delete medicine records, supporting efficient pharmacy management. The project is structured with a .NET backend and a modern React + TypeScript frontend.

## 🛠️ Tech Stack & Skills
- **Frontend:** React, TypeScript, Vite, Redux Toolkit, Tailwind CSS
- **Backend:** .NET (C#), Clean Architecture, Domain-Driven Design (DDD)
- **API Design:** RESTful APIs, layered architecture
- **Other:** Git, VS Code, Agile practices
